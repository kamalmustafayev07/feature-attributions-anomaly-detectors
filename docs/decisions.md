# Decisions log

Every deviation from the frozen design (execution plan of 2026-11-05, section 1.2) and every data-driven
decision (IF chance-level test, KernelSHAP fallbacks, rank saturation, GradientSHAP vs KernelSHAP for the AE)
is recorded here with the date, the numbers it was based on, the reason and who decided.

## Template

```
### YYYY-MM-DD — <short title>
- Decided by: <name>
- Context: <which checkpoint / script / table>
- Numbers: <the values the decision rests on, with the file they come from>
- Decision: <what changes, or "no change">
- Reason: <why>
- Affects: <configs / scripts / paper sections>
```
